# Fake Store

Catálogo de productos en Angular que obtiene los datos de [Fake Store API](https://fakestoreapi.com/products) mediante un `ProductService` con `HttpClient`. El componente `AppComponent` se suscribe al servicio y muestra título, categoría, precio e imagen de cada producto.

## Ejecución

```bash
npm install
ng serve
```

Abrir `http://localhost:4200`.
